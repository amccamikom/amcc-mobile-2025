# Pertemuan 1 - Explore Fundamental Dart Language🥳

Proyek ini berisi materi pembelajaran dasar pemrograman Dart yang mencakup konsep-konsep fundamental dalam bahasa pemrograman Dart.

📖 **Modul Pembelajaran**: [Explore Fundamental Dart Language - Medium](https://medium.com/amcc-amikom/explore-fundamental-dart-language-4930db45487b?postPublishedType=repub)

## 📚 Materi yang Dipelajari

### 1. Hello World ([hello_world.dart](bin/hello_world.dart))
- Program dasar Dart
- Penggunaan fungsi `main()`
- Output dengan `print()`
- Penggunaan variabel sederhana
- String interpolation dengan `$`

### 2. Tipe Data ([type_data.dart](bin/type_data.dart))
Mempelajari berbagai tipe data di Dart:
- **int**: Bilangan bulat (contoh: `2026`)
- **double**: Bilangan desimal (contoh: `3.14`)
- **num**: Tipe data numerik umum
- **String**: Teks/kata (contoh: `"We Are Mobile Rangers"`)
- **bool**: Nilai boolean (`true` atau `false`)
- **Map**: Koleksi data key-value
- **List**: Koleksi data terurut
- **dynamic**: Tipe data dinamis

### 3. Operator ([operator.dart](bin/operator.dart))
Operator yang dipelajari:
- **Operator Aritmatika**: `+`, `-`, `*`, `/`, `%`
- **Increment/Decrement**: `+=`, `-=`
- **Operator Perbandingan**: `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Operator Logika**: `&&` (AND), `||` (OR), `!` (NOT)

### 4. Percabangan ([percabangan.dart](bin/percabangan.dart))
Struktur kontrol percabangan:
- **if-else**: Percabangan kondisional
- **Conditional Expression**: Operator `??` (null coalescing)
- **Ternary Operator**: `kondisi ? nilai1 : nilai2`
- **switch-case**: Percabangan multi-kondisi

### 5. Perulangan ([perulangan.dart](bin/perulangan.dart))
Jenis-jenis perulangan:
- **for loop**: Perulangan dengan counter
- **while loop**: Perulangan dengan kondisi di awal
- **do-while loop**: Perulangan dengan kondisi di akhir

### 6. Komentar & Dokumentasi ([komentar.dart](bin/komentar.dart))
- Komentar satu baris (`//`)
- Komentar multi-baris (`/* */`)
- Dokumentasi kode dengan `///`
- Dokumentasi fungsi dan class
- Penggunaan parameter dalam dokumentasi

## 🚀 Cara Menjalankan

Untuk menjalankan setiap file, gunakan perintah:

```bash
dart run bin/nama_file.dart
```

Contoh:
```bash
dart run bin/hello_world.dart
dart run bin/type_data.dart
dart run bin/operator.dart
dart run bin/percabangan.dart
dart run bin/perulangan.dart
dart run bin/komentar.dart
```
